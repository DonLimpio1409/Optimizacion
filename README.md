Optimización de Escena en Unreal Engine

Descripción
En este proyecto se han aplicado distintas técnicas de optimización para mejorar el rendimiento de la escena en Unreal Engine.

Mejoras realizadas
Optimización de la iluminación.
Decimación de modelos 3D para reducir polígonos.
Fusión de actores mediante Merge Actors para disminuir draw calls.

Resultado
Se ha conseguido una escena más eficiente, con menor carga de renderizado y un mejor rendimiento general.
